## 安装包换图标（SFX 沿用原 Inno 图标）

要求："安装包图标沿用之前的" → 即原 Inno 安装包的图标。

**结论：Rar.exe 5.50 不支持 `-iicon`**（`rar -?` 只有 `-s` / `-sfx[name]`），
GUI 版才有。所以必须**先给 SFX 模块换图标，再用 `-sfx<模块>` 打包**。

⚠️ **不能直接改最终 SFX 的图标**：SFX = `[PE 模块][RAR 数据]`，
RAR 数据位置由模块大小决定；`UpdateResource` 会改变 PE 大小 → 偏移失配 → 包损坏。

### 流程

```
1. _extract_icon.py  原安装包 -> _icon_setup.ico       (纯标准库 PE 资源解析)
2. _set_sfx_icon.py  Default64.SFX + 图标 -> _sfx64_custom.SFX
3. _make_sfx.py      Rar.exe a ... -sfx_sfx64_custom.SFX -z_sfx_comment.txt
```
产物：**130.1 MB**，图标 md5 `7b6ee805f07ebcda` == 原安装包图标。端到端实测 PASS。

### 四个坑（都踩了）

**1. 图标组 ID 不能用自解析 PE 的值**：原安装包的 group 被解析成 `2147485190`
= `0x80000006`（高位 1 表示"字符串名"），是 bug。改用 **`EnumResourceNamesW`** 拿值。

**2. 资源语言实际是 `2052`（简体中文），不是 0**。
`UpdateResourceW` 删除时 lang 必须**精确匹配**，传 0 直接 `WinError 87`。
`EnumResourceLanguagesW` 才能拿到真值 —— 自解析 PE 把语言层读成 0。

**3. ctypes 调 `UpdateResourceW` 的正确姿势**：
- `lpType`/`lpName` 用 `ctypes.c_void_p`（**不要** `LPCWSTR`），
  MAKEINTRESOURCE 就是 `c_void_p(id)`
- `lpData` 用 `create_string_buffer(blob)` + `cast(..., c_void_p)`，
  **并保持 buffer 引用**（否则 GC 掉）
- 删除 = `lpData=None, cbData=0`

**4. `FreeLibrary` 必须设 `argtypes=[HMODULE]`**：
64 位下 HMODULE 值（如 `0x150D71F0002`）超过 `c_int` → `OverflowError`。
